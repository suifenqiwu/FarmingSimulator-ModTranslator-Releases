# 模拟农场 Mod 汉化工具

我们为 Windows 玩家制作了这款工具。你可以批量翻译 Mod 中的菜单、操作提示和物品说明，也可以为一个术语指定译法，在下一次汉化时继续使用。当前适配《模拟农场25》，其他代仍待验证。

## 第一次汉化

1. 下载并运行 EXE，在「汉化工作台」点击「新手引导」。橙框会指向当前操作位置，可以随时返回上一步或退出。
2. 打开「配置翻译服务」，选择主翻译，按「如何申请和填写密钥」里的对应教程保存自己的凭证。先测试连接，需要验证译文时再确认小量请求。二次校准可以先关闭。
3. 选择游戏 Mods 目录并扫描，勾选一个想汉化的 Mod。也可以从下载文件夹添加 ZIP 单独处理。
4. **从游戏 Mods 目录汉化时，请先关闭游戏。** 点击开始后，工具会在本批次开始前询问「完成后安装」。选择「复制到 Mods」，工具就会在每个 Mod 成功后自动把汉化包放回游戏目录，同时在【汉化完成】留一份结果。默认保留原 ZIP 名称时，游戏下次加载的就是同名汉化版。
5. 从普通下载文件夹处理时，在【汉化完成】中查看结果。需要装进游戏时，再到「Mod 管理」选择待安装的结果。

## 原件保护、安装与恢复

| 场景 | 工具怎样处理文件 |
| --- | --- |
| 在游戏目录开始处理 | 将选中的原 ZIP 移入【汉化更新】下的【原版未汉化】，集中保管原件。 |
| 完成并选择「复制到 Mods」 | 自动安装成功的结果。保留原文件名有助于维持地图、其他 Mod 和已有存档的引用。使用旧版可选的 _CN 后缀时，安装名称会不同。 |
| 完成但没有选择复制 | 成品留在【汉化完成】，原件留在托管区。之后可在「Mod 管理」安装成品或恢复原件。 |
| 部分条目翻译失败 | 部分汉化包存入【汉化待完善】，供修复后续译。游戏目录中的原件按恢复流程放回。 |
| 取消、失败或异常退出 | 失败或取消的项目尝试恢复到原路径。异常退出后，关闭游戏并重新扫描，工具会检查未完成的文件事务。发现同名冲突或内容变化时，请查看日志并按提示处理。 |

「Mod 管理」的已安装列表只看游戏 Mods 根目录。可以另行查看待安装结果、恢复上次安装或恢复未汉化原件；重复安装相同内容时会跳过。

## 翻译怎样利用上下文

同一个英文词在农机和界面里可能有两种译法。比如 `header` 与联合收割机相关时可译为「割台」，出现在表格列名时可译为「标题」。工具会结合原文、语言文件和条目键判断语境；线索不足的歧义词可以留给人工校对。你确认的特定语境译法可以优先使用。

- **词库与增量翻译。** 已有术语帮助统一名称。再次处理同一 Mod 时，工具可复用已有译文，让你把精力放在新增或变更的文字上。
- **独立的二次 AI 校准。** 主翻译支持阿里云机器翻译、百度通用翻译和兼容 Chat Completions 的服务。遇到需要复核的译文，可以让独立配置的校准服务结合上下文检查。校准可关闭，也可与主翻译使用不同服务商。
- **格式保护与人工修复。** 处理可识别的语言内容时保护占位符、变量和格式。失败条目保留文件、原文和上下文，方便在「人工修复失败条目」中定位、修改或续译。

## 日常使用与自定义外观

- **汉化工作台**记住上次选择的文件夹。后台扫描显示进度，支持按名称搜索、筛选新增 Mod、勾选筛选结果和批量处理。「检测到中文」表示发现了中文内容，不能单凭中文标题判断整包都已汉化。
- **任务与记录**显示批次结果和最近任务计数。遇到问题时可以展开运行日志，结合「检查 Mod 文件结构」查看压缩包和语言资源。
- **翻译服务**的普通模式按服务商展示所需字段；高级模式可调整模型、请求路径、语言映射、超时等适配器支持的参数。凭证在本机加密保存，小量翻译测试可能产生服务商费用。
- **设置与外观**提供浅色、深色和多套内置配色，也可以选自己的背景图片。调节图片可见度、遮罩颜色与强度，选择铺满或完整显示，实时预览后保存。喜欢的搭配可以另存为「我的皮肤」，或导出皮肤包分享给其他玩家。
- **软件更新**可在设置中手动检查正式版本、阅读更新说明，再打开官方下载页获取新版。
