# 模拟农场 Mod 汉化工具

我们做了这款 Windows 工具，帮助玩家把 Mod 里的菜单、操作提示和物品说明翻译成中文。目前适配《模拟农场25》，其他代的兼容性仍待验证。

**[下载最新版本](https://github.com/suifenqiwu/FarmingSimulator-ModTranslator-Releases/releases/latest)** · [查看历次更新](https://github.com/suifenqiwu/FarmingSimulator-ModTranslator-Releases/releases)

## 可以用它做什么

- **找出要汉化的 Mod。** 扫描 Mods 文件夹或添加 ZIP，按名称搜索并勾选要处理的模组。列表会显示是否检测到中文，方便初筛；少量中文也会被检测到，具体翻译程度仍需查看内容。
- **选用自己的翻译服务。** 主翻译可选阿里云机器翻译、百度通用翻译或支持 Chat Completions 的服务。二次 AI 校准独立配置，也可以关闭。凭证在本机加密保存，实际费用取决于你所选服务。
- **批量翻译并沿用已有译文。** 词库帮助统一术语，增量翻译复用已有结果。工具处理可识别的语言文件，并检查格式和占位符，尽量保留游戏显示文字时需要的变量。
- **处理遗漏与失败条目。** 翻译后可查看任务结果，对待完善条目进行人工校对、修复或续译。
- **保留原件和文件名。** 从游戏 Mods 目录处理时，工具会保护原件。汉化结果可以保留原 ZIP 文件名，方便已有存档和依赖其他模组的地图继续引用，也可以在 Mod 管理中恢复原件。

## 第一次使用

1. 下载并运行 EXE，在工作台点击「新手引导」，跟随橙框操作。
2. 打开「配置翻译服务」，选择主翻译。点击「如何申请和填写密钥」查看对应教程，再填写自己的凭证并保存。
3. 点击「添加 ZIP」选一个 Mod，勾选并开始汉化。完成后打开「汉化完成」查看结果，再按提示安装到游戏。
